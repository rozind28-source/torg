# 🧠 Smart TradingView Browser

Умный браузер для анализа графиков TradingView с функциями компьютерного зрения и AI-анализа.

## 🚀 Возможности

- **Встроенный браузер** - просмотр TradingView без переключения между окнами
- **Захват скриншотов** - сохранение графиков одним кликом
- **AI-анализ** - автоматическое определение:
  - Направления тренда (бычий/медвежий/боковой)
  - Уровней поддержки и сопротивления
  - Волатильности рынка
- **История анализов** - отслеживание всех проведенных анализов
- **Экспорт результатов** - сохранение отчетов в текстовом формате

## 📋 Требования

- Python 3.8 или выше
- Операционная система: Windows, macOS, Linux

## 🔧 Установка

### 1. Клонируйте репозиторий или перейдите в директорию проекта

```bash
cd tradingview-smart-browser
```

### 2. Создайте виртуальное окружение (рекомендуется)

**Windows:**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

Или вручную:

```bash
pip install PyQt6 PyQt6-WebEngine numpy Pillow opencv-python-headless
```

## ▶️ Запуск

```bash
python src/main.py
```

## 📖 Использование

1. **Запустите приложение** - откроется окно со встроенным браузером
2. **Перейдите на TradingView** - по умолчанию загружается https://www.tradingview.com/chart/
3. **Настройте график** - выберите актив, таймфрейм, индикаторы
4. **Сделайте скриншот** - нажмите кнопку "📸 Скриншот" или "Сделать скриншот"
5. **Проанализируйте** - нажмите "🔍 Анализировать" для получения AI-анализа
6. **Сохраните результат** - экспортируйте анализ в текстовый файл

## ⚙️ Компоненты

### ChartAnalyzer
Класс для анализа изображений с использованием OpenCV:
- Определение тренда по распределению границ
- Поиск горизонтальных уровней (поддержка/сопротивление)
- Расчет волатильности

### SmartBrowser
Основное окно приложения:
- QWebEngineView для отображения веб-контента
- Панель инструментов с кнопками действий
- Панель анализа с результатами и историей

## ⚠️ Примечания

- Для корректной работы требуется установленный браузерный движок Chromium (входит в PyQt6-WebEngine)
- Функция захвата скриншотов в текущей версии создает тестовое изображение. Для полноценной работы требуется доработка с использованием `QWebEnginePage.printToPdf()` или аналогичных методов
- Анализ графиков основан на простых эвристиках компьютерного зрения. Для торговых решений рекомендуется использовать дополнительные инструменты
