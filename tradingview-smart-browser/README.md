# 🧠 Smart TradingView Browser

Умный браузер для анализа графиков TradingView с использованием компьютерного зрения и AI.

## 🚀 Возможности

- **Встроенный браузер** - полноценный доступ к TradingView
- **Захват скриншотов** - автоматическое сохранение графиков
- **AI-анализ** - распознавание трендов, уровней поддержки/сопротивления
- **Технический анализ** - определение волатильности и паттернов
- **История анализов** - сохранение и экспорт результатов
- **Экспорт данных** - сохранение отчетов в текстовом формате

## 📋 Требования

- Python 3.8+
- PyQt6
- PyQt6-WebEngine
- OpenCV (opencv-python)
- NumPy
- Pillow

## 🔧 Установка

### 1. Клонирование или создание проекта

```bash
cd tradingview-smart-browser
```

### 2. Создание виртуального окружения (рекомендуется)

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей

```bash
pip install PyQt6 PyQt6-WebEngine opencv-python numpy pillow
```

## 🎯 Запуск

```bash
python src/main.py
```

Или через npm скрипт:

```bash
npm start
```

## 💡 Как использовать

1. **Запустите приложение** - откроется окно с встроенным браузером
2. **Перейдите на TradingView** - по умолчанию загружается https://www.tradingview.com/chart/
3. **Откройте нужный график** - выберите актив, таймфрейм, индикаторы
4. **Сделайте скриншот** - нажмите кнопку "📸 Скриншот" или "Сделать скриншот"
5. **Проанализируйте** - нажмите "🔍 Анализировать" для получения AI-анализа
6. **Сохраните результат** - экспортируйте анализ в текстовый файл

## 📊 Функции анализа

### Определение тренда
- 📈 **BULLISH** - восходящий тренд
- 📉 **BEARISH** - нисходящий тренд  
- ➡️ **SIDEWAYS** - боковое движение

### Уровни поддержки и сопротивления
Автоматическое обнаружение ключевых ценовых уровней на основе анализа гистограммы ребер изображения.

### Волатильность
Расчет волатильности на основе стандартного отклонения яркости пикселей.

### Рекомендации
AI генерирует торговые рекомендации на основе выявленных паттернов.
